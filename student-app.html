오늘의 레벨 테스트 앱

앱을 누르면 바로 오늘 문제가 나와요. 새 문제는 매일 오후 3시에 올라와요.

버튼이 안 되면 여기를 길게 눌러 '링크 다운로드'

설치 방법 (부모님과 함께 해 주세요)
  1. "앱 받기"를 누르면 leveltest-student.apk가 저장돼요. 화면 아래나 알림창에 뜬 파일을 눌러요.
  2. "출처를 알 수 없는 앱" 허용을 묻으면 설정 → 허용을 켜고 돌아와 설치를 눌러요.
  3. "Play 프로텍트" 경고가 나오면 자세히 → 무시하고 설치를 눌러요. 선생님이 직접 만든 앱이라 나오는 안내예요.
  4. 홈 화면의 오늘의 레벨 테스트 아이콘을 누르고, 이름과 학년을 한 번만 입력하면 끝!
아이폰은 앱 파일을 설치할 수 없어요.
대신 이 링크를 열고, 아래쪽 공유 버튼 → 홈 화면에 추가를 누르면 앱처럼 아이콘으로 쓸 수 있어요.

앱 없이 바로 풀려면: 오늘의 레벨 테스트 열기
