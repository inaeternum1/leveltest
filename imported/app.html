레벨테스트 관리 앱

선생님 폰(안드로이드)에 설치하는 채점·관리 앱이에요. 파일 크기 33KB.

위 버튼이 안 되면 여기를 길게 눌러 '링크 다운로드'

설치 방법
  1. "앱 파일 받기"를 누르면 leveltest-teacher.apk가 저장돼요. 화면 아래나 알림창에 뜨는 파일을 눌러 주세요.
  2. "출처를 알 수 없는 앱" 설치를 허용하라고 나오면 설정 → 허용을 켜고 뒤로 돌아와 설치를 누르세요.
  3. "Play 프로텍트" 경고가 나오면 자세히 → 무시하고 설치를 누르세요. 직접 만든 앱이라 나오는 안내예요.
  4. 앱을 처음 열면 채점 주소를 한 번만 붙여넣어 주세요.
다운로드가 멈추면
  1. 폰의 내 파일 → 다운로드에 이미 받아져 있는지 확인해 보세요.
  2. 크롬이라면 주소창 오른쪽 ⋮ → 다운로드에서 멈춘 항목을 지우고 다시 받아 보세요.
  3. 와이파이 대신 모바일 데이터로(또는 그 반대로) 바꿔서 다시 해 보세요.
