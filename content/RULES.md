# 매일 레벨 테스트 출제 규칙 (4학년·5학년)

매일 오후 3시(한국 시간)에 그날 날짜로 4학년 세트 1개, 5학년 세트 1개를 만든다.
학생 주소: https://inaeternum1.github.io/leveltest/level-test.html
정답·해설은 선생님이 교사 화면에서 OK를 누르기 전까지 학생에게 보이지 않는다.

## 1. 세트 구성
- 하루 13문항 (아이들이 매일 부담 없이 풀 수 있게 줄임, 2026-10-20부터). 이 순서 그대로:
  1. 국어 3(k, 1~3번): **긴 지문 1편**을 3문항이 함께 쓴다.
  2. 영어 3(e, 4~6번): **긴 영어 지문 1편**을 3문항이 함께 쓴다.
  3. 영어 듣기 2(l, 7~8번)
  4. 수학 2(m, 9~10번): **둘 다 사고력 문제**(숫자 입력). 교과 4지선다 수학 문제는 내지 않는다.
  5. 과학 3(s, 11~13번)
- **스도쿠(2026-10-23부터)**: 저장 함수(admin_upsert_set)가 사고력 수학 바로 뒤에 스도쿠 1문항을 문제 은행(public.sudoku_bank)에서 꺼내 **자동으로** 붙인다. 그래서 학생 화면은 14문항(스도쿠가 11번, 과학이 12~14번)이 된다. 출제할 때는 지금처럼 13문항만 만들고, 스도쿠는 만들거나 JSON에 넣지 않는다(`sudoku`·`sol` 키를 넣으면 거부된다).
  - 4학년은 '어려움'(단일 후보 찾기만으로 풀리되 빈칸 54~57개), 5학년은 '더 어려움'(후보 줄이기가 꼭 필요, 찍기는 필요 없음). 모두 정답이 하나뿐인 것만 코드로 확인해 넣었다(tools/sudoku_bank.py).
  - 저장 결과 끝에 `스도쿠 남은 N개`가 나온다. 20개 아래로 떨어지면 선생님께 알리고, tools/sudoku_bank.py로 새로 만들어 채운다.
- 객관식은 보기 4개, 정답은 하나만 확실해야 한다. JSON에서는 **첫 번째 보기가 정답**으로 쓰고, 저장 함수가 보기 순서를 섞는다.
- "모두 고르시오", "옳지 않은 것 2개" 같은 형식 금지. 부정형("알맞지 않은 것")은 세트당 1개 이하, 문장에 '않은'을 분명히 쓴다.
- 서술형(open)은 국어에서만, 세트당 최대 1개(없어도 됨). 모범 답안(model) 필수.
- 모든 문항에는 화면이 '잘 몰라요 (찍지 않고 넘기기)' 보기를 자동으로 붙인다. JSON 보기에 '모르겠다' 같은 항목을 넣지 않는다.
- 난이도: 국어·영어·과학은 교과서·익힘책 기본~중간, 과목마다 마지막 문항만 조금 응용. 문항이 적으니 한 문항 한 문항이 그 단원의 핵심 개념을 묻게 한다.
- 국어 지문 3문항은 서로 다른 능력을 묻는다(예: 낱말 뜻 1 + 내용 이해 1 + 중심 생각·요약·추론 1). 영어 지문 3문항도 세부 내용·낱말·전체 내용(주제·제목·추론)을 섞는다.
- 문장은 아이가 한 번에 읽히게 짧고 자연스럽게. "끈 4/5 m 중에서 3/8만큼을"처럼 어색한 표현 대신 "끈이 4/5 m 있어요. 그중 3/8을 사용했어요."처럼 두 문장으로 나눈다.
- 해설(exp)은 학생이 읽는 친근한 말투(~예요/~해요)로 1~2문장. 왜 정답인지 핵심만.
- 같은 날 4학년·5학년 문제가 겹치지 않게, 최근 10일 문항과도 겹치지 않게(아래 절차로 확인).

## 2. 학년별 범위 (2022 개정 교육과정, 2026학년도)
2학기 단원은 달에 따라 넓힌다. 학교·출판사마다 진도가 다를 수 있으니 애매하면 1학기·이전 학년 내용으로 낸다.

### 4학년
- **수학**
  - 1학기: 큰 수(만·억·조, 자릿값, 뛰어 세기, 크기 비교), 각도(각도 재기, 예각·둔각, 삼각형 세 각의 합 180°, 사각형 네 각의 합 360°), 곱셈과 나눗셈(세 자리×두 자리, 두 자리 수로 나누기, 나머지), 평면도형의 이동(밀기·뒤집기·돌리기), 막대그래프, 규칙 찾기
  - 2학기: 10월 = 분수의 덧셈과 뺄셈(분모가 같은 분수만, 대분수 포함), 삼각형(이등변·정삼각형, 예각·둔각·직각삼각형) / 11월 = + 소수의 덧셈과 뺄셈(소수 두 자리), 사각형(수직·평행, 사다리꼴·평행사변형·마름모 성질) / 12월~ = + 꺾은선그래프, 다각형(정다각형, 대각선)
  - 금지: 통분·약분, 약수·배수, 넓이 공식, 소수의 곱셈, 분모가 다른 분수 계산
- **과학**
  - 3학년 전 범위 기초 + 4-1: 자석의 이용, 물의 상태 변화(증발·끓음·응결), 땅의 변화(흐르는 물, 강 주변 지형, 화산·화성암), 다양한 생물(균류·원생생물·세균)
  - 2학기: 10월 = 밤하늘 관찰(달의 모양 변화, 태양계 구성원, 북극성·별자리), 생물과 환경(생태계 구성 요소, 먹이 관계) / 11월 = + 여러 가지 기체(기체의 무게, 온도·압력과 부피) / 12월~ = + 기후변화
  - 교과서 출판사마다 단원 배치가 다를 수 있으므로 특정 교과서 실험 이름에 의존하지 말고 개념으로 묻는다.
- **영어** (3~4학년군 수준)
  - 낱말: 색, 숫자 1~100, 동물, 음식, 과일, 날씨, 요일, 가족, 몸, 학교 물건, 장소
  - 표현: 인사, What's this?, How many ~?, Can you ~? / I can ~, Do you like ~?, What time is it?, Where is ~? (in/on/under), What day is it?, How's the weather?
  - 문법: be동사, 일반동사 현재형, 명령문, 복수형 -s.
  - 지문: 짧은 문장 6~9개로 된 글 1편(자기소개·편지·일기·안내문·이야기 등, 150~400자). 질문은 한국어로, 보기는 한국어 또는 짧은 영어.
  - 금지: 과거형, 미래형, 비교급·최상급, 조건문(if), 완료형
- **국어**
  - 400~600자 설명문 또는 이야기 1편을 3문항이 공유(passage). 중심 문장·중심 생각, 낱말 뜻(문맥), 인물의 마음, 일이 일어난 차례
  - 맞춤법·높임 표현·속담·이어 주는 말(그래서·그러나·그런데)은 따로 문항을 만들지 말고, 지문 속 낱말·문장으로 묻는다(예: "㉠에 들어갈 이어 주는 말은?").

### 5학년
- **수학**
  - 4학년 전 범위 + 5-1: 자연수의 혼합 계산, 약수와 배수(최대공약수·최소공배수), 대응 관계, 약분과 통분, 분수의 덧셈과 뺄셈(분모가 다른 분수), 다각형의 둘레와 넓이(직사각형·평행사변형·삼각형·사다리꼴·마름모, cm²·m²)
  - 2학기: 10월 = 수의 범위와 어림하기(이상·이하·초과·미만, 올림·버림·반올림), 분수의 곱셈 / 11월 = + 합동과 대칭, 소수의 곱셈 / 12월~ = + 직육면체(겨냥도·전개도), 평균과 가능성
  - 금지(6학년): 분수·소수의 나눗셈, 비와 비율·백분율, 비례식·비례배분, 원주·원의 넓이, 겉넓이·부피, 각기둥·각뿔, 원기둥
- **과학**
  - 4학년 전 범위(위 4학년 과학 1·2학기 전체) + 5-1: 지층과 화석, 빛의 성질(직진·반사·굴절, 거울과 렌즈의 이용), 용해와 용액(용질·용매, 녹는 양에 영향을 주는 조건, 진하기), 우리 몸의 구조와 기능(뼈·근육, 소화·순환 기관)
  - 5-2 단원은 아직 확인되지 않았으므로 출제하지 않는다(선생님이 알려 주면 이 문서를 고친다).
  - 금지(6학년·중등): 산과 염기, 광합성 세부, 전기 회로의 직렬·병렬, 연소와 소화, 계절 변화의 원인
- **영어** (5~6학년군 초반)
  - 4학년 범위 + 과거형(규칙, 자주 쓰는 불규칙 went·ate·saw·had·did·made·got), 위치(next to, between, across from), 직업·장래 희망(I want to be ~), 좋아하는 것(What's your favorite ~?), 소유(Whose ~ is this?), 빈도(always, usually, sometimes), 가격(How much ~?), 길 묻기
  - 지문: 8~12문장으로 된 글 1편(일기·편지·이메일·안내문·이야기 등, 300~700자). 질문은 영어 또는 한국어, 보기는 짧게.
  - 금지: 조건문(if), 현재완료, 관계대명사, 수동태, 최상급 비교 구문(the most ~ of …)
- **국어**
  - 600~900자 지문 1편을 3문항이 공유. 요약하기, 사실과 의견 구별, 주장과 근거, 글의 구조(비교·대조, 원인·결과), 비유 표현
  - 맞춤법·높임 표현(주체·객체)·관용 표현·낱말의 뜻 관계(동형어·다의어)는 따로 문항을 만들지 말고 지문 속 낱말·문장으로 묻는다.

### 사고력 수학 (수학은 이 2문항뿐, 9·10번, 두 학년 공통 형식)
- 수학은 **사고력 문제 2문항만** 낸다(9·10번). 교과 4지선다 문제는 없다.
- **핵심: 배운 것을 최대한 활용해서, 오래 생각하면 풀 수 있는 문제.** 낯선 공식이나 요령을 알아야 풀리는 문제가 아니라, 그 학년에서 배운 개념(계산·도형·분수·약수와 배수 등)을 여러 번, 여러 단계로 써야 답에 이르는 문제다.
  - 9번: **지금 배우고 있는 단원(이번 달 2학기 단원)** 개념을 중심으로. 예) 4학년 10월 분수의 덧셈과 뺄셈 → 조건을 만족하는 분수 찾기, 5학년 10월 분수의 곱셈·어림 → 조건을 거꾸로 따라가기.
  - 10번: **이전에 배운 단원 두 가지 이상을 섞어서.** 예) 4학년 각도 + 규칙 찾기, 5학년 약수·배수 + 넓이.
  - 두 문항 모두 4~6단계 생각이 필요하게: 조건 정리 → 식이나 표 세우기 → 경우 좁히기 → 확인. 아이가 5~10분 고민해야 풀리는 정도. 단순 계산만 길게 늘인 문제나, 한 번 떠올리면 바로 풀리는 '함정' 문제는 내지 않는다.
- 형식: `"num": true, "ans": "정답 숫자"` 를 쓰고 **options는 넣지 않는다**. 학생이 숫자를 직접 입력하고 자동 채점된다. 정답은 정수(또는 끝나는 소수) 하나로 딱 정해져야 한다. 분수가 답이 되는 문제는 내지 않는다.
- **해당 학년까지 배운 개념만으로 풀 수 있어야 한다.** 새 공식이나 윗학년 내용을 쓰지 않는다. 대신 생각을 여러 단계 해야 풀리게 만든다. 계산만 길게 늘인 문제는 사고력 문제가 아니다.
- 유형(매일 겹치지 않게 돌아가며): 규칙 찾기(수 배열·도형 배열의 n번째), 거꾸로 생각하기, 조건을 모두 만족하는 수 찾기, 빠짐없이 세기(경우 나열·도형 개수 세기), 표·그림을 이용한 추론, 논리 퍼즐(누가 무엇을), 수 만들기(숫자 카드), 마방진·빈칸 채우기, 나이·묶음·나눠 담기 문장제, 5학년은 약수·배수·최소공배수 활용, 넓이·둘레 활용, 대응 관계 식 세우기.
- 난이도: 교과서 '도전 문제'·단원평가 최상 수준. 문제 문장은 짧고 분명하게 써서, 어려운 것은 '생각'이지 '문장 이해'가 아니게 한다.
- **정답은 반드시 직접 검산한다.** 경우를 세는 문제는 가능하면 코드로 전부 세어 확인한다. 답이 하나로 정해지지 않거나 조건이 애매하면 버리고 다시 만든다.
- unit은 `사고력 · 유형` 꼴로 쓴다(예: `사고력 · 규칙 찾기`).
- 해설(exp)은 풀이 순서를 2~4문장으로, 어떻게 생각하면 되는지 보여 준다(답만 쓰지 않는다).

### 영어 듣기 (두 학년 공통 형식, s = "l")
- 화면이 대본(script)을 휴대폰 음성으로 읽어 준다. 풀 때 대본 글자는 보이지 않고, 선생님이 OK한 뒤 결과 화면에 대본이 나온다.
- script는 **영어로만**(한글 금지) 쓴다. 대화는 줄마다 `A: ` 또는 `B: `로 시작한다(A·B는 목소리 높낮이로 구분됨). 한 사람이 말하면 표시 없이 1~2문장.
- 음성으로 읽기 좋게: 짧고 또렷한 문장, 숫자는 단어로(three o'clock, twenty dollars), 축약형은 교과서에서 쓰는 것만(It's, I'm, Don't). 괄호·기호·이모지 금지.
- 질문(q)은 한국어로, 무엇을 들어야 하는지 분명히 쓴다. 예: "대화를 듣고, 여자아이가 좋아하는 과일을 고르세요."
- 보기는 한국어 또는 짧은 영어. 대본에 나온 낱말을 오답 보기에도 섞어 끝까지 들어야 풀 수 있게 한다. 정답이 대본으로 하나만 확실해야 한다.
- 해설(exp)에는 정답의 근거가 된 대본 문장을 영어로 인용하고 뜻을 덧붙인다.
- passage는 쓰지 않는다(대본은 script에만).
- 하루 2문항(7·8번). 하나는 '헷갈리게 하기' 또는 '정보 합치기', 하나는 '추론'으로 낸다.
- **난이도: 대본에 답이 그대로 한 번만 나오는 쉬운 문제는 내지 않는다.** 두 문항 모두 아래처럼 끝까지 듣고 정리·비교·추론해야 풀리게 만든다.
  - 헷갈리게 하기: 대본에 오답 정보도 함께 나온다(처음 말한 것을 바꿈 "Not the red one. I want the blue one.", 두 사람이 각각 다른 것을 말함, thirteen/thirty 같은 비슷한 숫자).
  - 정보 합치기: 두 가지 이상을 들어야 답이 나온다(가격 두 개를 더함, 시각 + 30분 뒤, 위치를 두 번 설명).
  - 추론: 대화가 일어나는 장소, 두 사람의 관계, 다음에 할 일, 말하는 사람의 기분이나 이유, 대화의 마지막 말에 이어질 알맞은 응답.
  - 질문 대상 바꾸기: "B가"가 아니라 "A가 원하는 것", "두 사람이 함께 할 일"처럼 누구의 말을 들어야 하는지 주의하게 한다.
- **4학년**: 3~5줄 대화. 날씨, 시각, 개수, 위치 in/on/under/next to, 좋아하는 것, Can you ~?, 물건·색깔·가족. 위 4학년 영어 범위의 낱말·표현만 쓴다.
- **5학년**: 5~8줄 대화 또는 4~6문장 안내 방송·설명. 지난 일(과거형), 계획, 장래 희망, 길 안내(두 번 꺾기), 가격 계산, 일정. 위 5학년 영어 범위만 쓴다.
- 영어 지문(4~6번)과 듣기 대본은 소재가 겹치지 않게 한다.

## 3. 분수 표기 (교과서처럼 위아래로 보이게)
- 분수는 반드시 `[[분자/분모]]`로 쓴다. 예: 4분의 3 → `[[3/4]]`
- 대분수는 `[[자연수 분자/분모]]`. 예: 2와 7분의 3 → `[[2 3/7]]`
- 문제·보기·해설·모범 답안 모두 적용. 'N분의 M'이나 맨 '3/4'는 쓰지 않는다(저장 함수가 거부한다).
- 정답 보기는 기약분수·대분수 형태로 쓰고, 값이 같은 다른 표현(예: [[12/40]]과 [[3/10]])을 다른 보기에 넣지 않는다.

## 4. 그림(fig)
- 도형·그래프 등 그림이 있어야 풀 수 있는 문제는 SVG를 fig에 넣는다. 그림 없이 풀 수 없는 문제를 그림 없이 내지 않는다.
- `<svg viewBox="0 0 240 150" role="img" aria-label="설명">` 형태, 색은 `currentColor`, 글자 font-size 13~16, 6000자 이하. script·이벤트 속성·외부 이미지·href 금지.
- 수치와 그림 비율이 실제로 맞는지 확인한다(예: 각도 그림은 실제 각도와 비슷하게).

## 6. 올리는 절차 (Supabase 프로젝트 inulbquzdxzinpidgwhh, execute_sql)
1. 오늘 세트가 이미 있는지: `select grade from public.sets where date = 'YYYY-MM-DD';` → 있는 학년은 만들지 않는다.
2. 최근 문항 확인: `select * from public.recent_topics(4);` (5학년은 5)
3. 사고력 수학 2문항은 정답을 직접 다시 계산하고, 가능하면 코드로 경우를 전부 세어 답이 하나인지 확인한다.
4. 저장: `select public.admin_upsert_set('YYYY-MM-DD', 4, $json$[ …13문항… ]$json$::jsonb);`
   - 결과가 `created · 정답 위치: …`이면 성공. `검증 실패: …`이면 그 내용을 고쳐 다시 실행한다.
   - `exists`이면 이미 있는 것이니 덮어쓰지 않는다(네 번째 인자 true는 선생님이 요청할 때만).
5. 확인: `select date, grade, jsonb_array_length(questions) from public.sets where date = 'YYYY-MM-DD';`
